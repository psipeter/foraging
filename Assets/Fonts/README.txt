UI text (UiStyle.cs): titles in Nunito ExtraBold, everything else in Nunito Sans Regular (Nunito Sans Bold for bold runs); Inter (Inter.ttf, the variable
font's default Regular instance) was used before 2026-11-06 and is kept as a fallback asset.

Nunito (Nunito-ExtraBold.ttf: the variable font's wght 800 instance) and Nunito Sans (NunitoSans-Regular.ttf, NunitoSans-Bold.ttf: wght 400 and 700, the
default width, optical size and YTLC), made from the variable fonts in github.com/google/fonts (ofl/nunito, ofl/nunitosans) with fontTools' instancer.
