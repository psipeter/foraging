# Code map

The file-by-file structure of the repository (moved out of `CLAUDE.md` on 2026-11-19 to keep it short; `CLAUDE.md` keeps one line per
directory). **Keep this tree in sync when files are added, moved, or retired.** Docs that were deleted on 2026-11-19 (`EXPERIMENTS.md`,
`CLEANUP_PLAN.md`, `VALIDATION_PLAN.md`, `reviews/`) live on in `docs/DECISIONS.md`, historical entries, and in git history.

Besides the tree below: `archive/` (`abab/`, `cf_ladder/`: retired designs), `results/` (gitignored: the simulator's results database, figures,
perf runs), `ForagingData/` (gitignored: local copies of logged runs, `_worlds/`), `README.md` (short, human-facing).
